# Kognitiv Systems Website

A premium static landing page for Kognitiv Systems.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any simple static server.

Example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Files
- `index.html` — page structure and content
- `styles.css` — visual system, motion and responsive layout
- `script.js` — intro animation, scroll reveal, glow and tilt interactions
- `assets/kognitiv-full.png` — original supplied logo artwork
- `assets/logo-symbol.png` — separated symbol asset
- `assets/logo-wordmark.png` — separated Kognitiv Systems wordmark

No frameworks or external libraries are required.
